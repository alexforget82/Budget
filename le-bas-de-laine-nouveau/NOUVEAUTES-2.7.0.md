# Le Bas de Laine 2.7.0

## Revue de la semaine

Le nouveau bouton **Revue rapide** de l’accueil rassemble les vérifications
utiles dans une seule fenêtre :

- solde bancaire à confirmer ou déjà à jour ;
- dépenses sans limite à classer ;
- échéances passées qui attendent une décision ;
- aperçu des revenus et factures des sept prochains jours.

Les boutons vont directement à la bonne action. La revue n’enregistre rien et
ne change jamais le Safe-to-Spend : elle sert uniquement à savoir quoi vérifier.

## Installation

Utilisez le script `Mettre-a-jour-Le-Bas-de-Laine-2.7.0.sh` inclus dans cette
archive. Il sauvegarde les données et revient automatiquement à la version
précédente si le démarrage sur le port 3045 échoue.
