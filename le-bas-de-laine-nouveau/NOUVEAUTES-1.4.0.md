# Le Bas de Laine 1.4.0

Cette version concerne l’installation active sur le port **3045**.

- Transactions : tri par date, montant, description ou limite; filtres par mois, moyen et opérations à classer.
- Règles par commerçant : IGA peut proposer Épicerie, Shell une limite d’essence, avec option par moyen de paiement.
- Saisie : une règle propose la limite automatiquement et peut être mémorisée depuis l’achat.
- CSV : aperçu, choix des colonnes, catégories modifiables avant import et détection des lignes déjà importées.
- À classer : accès rapide aux dépenses sans limite, sélection avec total/moyenne et classement en lot.
- Export : inclut désormais les règles de commerçant, les ajustements de limites et les identités d’import.

Les formules du disponible, les limites, les récurrences, le port 3045, Tailscale et la vue simplifiée restent inchangés. Une copie complète de l’application et des données est créée avant la mise à jour; le script revient automatiquement en arrière si la 1.4.0 ne démarre pas.
