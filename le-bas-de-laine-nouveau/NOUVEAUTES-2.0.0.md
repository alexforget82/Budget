# Le Bas de Laine 2.0.0

## Un calendrier qui sert au suivi quotidien

Le calendrier montre maintenant ensemble :

- une opération **saisie** manuellement ou importée ;
- un revenu ou une facture **prévu(e)** ;
- une échéance **payée**, **déplacée** ou **ignorée** ;
- le renouvellement d’une limite.

Touchez une opération réelle pour la modifier. Touchez une échéance prévue pour
la marquer payée, la déplacer ou l’ignorer. Le calendrier reste une vue : il ne
change aucun calcul tant qu’aucune action n’est choisie.

## Boîte de réception des dépenses à classer

Dans **Transactions**, le filtre **Boîte de réception · à classer** rassemble
les dépenses sans limite. C’est utile après un import CSV : classez-les en lot
pour que les restants de vos limites restent exacts.

## Installation

Lancez le script `Mettre-a-jour-Le-Bas-de-Laine-2.0.0.sh` inclus dans
l’archive. Il conserve vos données, fait une copie complète avant la mise à
jour et vérifie que le service répond sur le port 3045.
