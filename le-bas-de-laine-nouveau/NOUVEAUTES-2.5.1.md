# Le Bas de Laine 2.5.1

## Vue foyer iPhone corrigée

- La vue simplifiée a maintenant son propre manifeste d’application.
- Son raccourci iPhone ouvre directement `/simple`, plutôt que l’application
  complète.
- Les adresses `/simple` et `/simple/` sont toutes deux reconnues.

Après la mise à jour, supprimez l’ancienne icône de la vue foyer sur l’iPhone,
puis ouvrez l’adresse `/simple` dans Safari et ajoutez-la à l’écran d’accueil.

## Installation

Utilisez le script `Mettre-a-jour-Le-Bas-de-Laine-2.5.1.sh` inclus dans cette
archive. Il sauvegarde les données et revient automatiquement à la version
précédente si le démarrage sur le port 3045 échoue.
