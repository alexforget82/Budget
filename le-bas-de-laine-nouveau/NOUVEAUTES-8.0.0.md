# Le Bas de Laine 8.0.0 — Atelier

Une nouvelle interface complète, sans modifier les calculs ni les données :

- Accueil centré sur le point bas, la trajectoire de 30 jours et les événements qui la font bouger.
- Registre de transactions dense, recherche, filtres, modification et règles de commerçant.
- Plan en trois flux lisibles : revenus, factures et limites, avec ajout, modification et suppression directs.
- Calendrier cliquable : touchez une journée pour développer tous ses éléments, puis une échéance pour la payer, la déplacer ou l’ignorer.
- Budget mensuel en tableau compact.
- Vérification du solde et « Puis-je acheter ? » sont disponibles dans la nouvelle interface.
- La vue simple `/simple` reste inchangée pour l’iPhone partagé.

L’ancienne interface est conservée temporairement à `/classic` comme porte de retour visuelle. Les mêmes données et le même moteur sont utilisés dans les deux vues.
