# Le Bas de Laine 4.0.0 — Une interface plus claire

Cette version renouvelle entièrement la présentation de l’application. Les
montants, les calculs de Safe-to-Spend, les limites, les récurrences et les
données existantes ne changent pas.

## Ce qui est nouveau

- Une navigation plus légère, pensée comme un logiciel de budget : les pages
  importantes sont immédiatement lisibles et les actions secondaires restent
  discrètes.
- **Transactions** devient un registre compact : recherche, filtres, montants,
  comptes et catégories se consultent dans une même grille dense.
- **Budget** reprend la logique d’une feuille budgétaire : budget, dépensé,
  restant et progression sont alignés par catégorie.
- **Plan** s’ouvre sur trois résumés (revenus, factures, limites). Chaque
  groupe se déplie seulement quand vous voulez le gérer, ce qui évite une longue
  page de récurrences.
- **Calendrier** est allégé pour faire ressortir les jours et les opérations.
- L’accueil garde le Safe-to-Spend au centre, avec des cartes plus lisibles et
  les limites ainsi que les prochaines opérations côte à côte sur ordinateur.
- Les deux vues iPhone sont adaptées au nouveau style : votre vue complète
  conserve toutes les fonctions; la vue `/simple` de votre conjointe reste
  limitée, claire et en lecture seule.

## Ce qui reste volontairement identique

- Aucun calcul de limite, de récurrence, de carte ou de Safe-to-Spend n’est
  modifié.
- Aucun compte, transaction, règle ou réglage n’est déplacé ni supprimé.
- Le mode sombre reste disponible dans **Apparence**.

La mise à jour crée une copie complète des données et revient automatiquement à
la version précédente si le démarrage ne réussit pas.
